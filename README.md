# Père-Lachaise guidé

Visite guidée vocale et géolocalisée du cimetière du Père-Lachaise (Paris) : choisir une personnalité, puis suivre les consignes vocales jusqu'à sa tombe.

Site : https://kevindepassage.github.io/pere-lachaise-guide/

Données : positions des sépultures © contributeurs OpenStreetMap (ODbL) via la base SuperLachaise ; descriptions Wikidata (CC0) ; coordonnées des portes : paris.fr.
